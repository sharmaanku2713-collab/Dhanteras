# ASAI LABS — Interactive Diwali & Dhanteras Greeting Experience 🪔✨

> **"Your Vision. Our Creation."**  
> Modern, animated, mobile-first festive greeting websites built for **ASAI LABS** to celebrate Happy Dhanteras and Happy Diwali with personalized WhatsApp sharing.

---

## 🌟 Project Highlights

- **Two Distinct Festive Worlds**:
  - **Happy Dhanteras** (`/dhanteras`): Traditional golden kalash, coin shower canvas, marigold torans, clay diyas, and prosperity blessings.
  - **Happy Diwali** (`/diwali`): Midnight celestial sky, interactive fireworks canvas (click/touch to launch fireworks!), hanging akash kandils, and sacred rangoli centerpiece.
- **Cinematic Cloud Reveal Sequence**:
  1. *Initial Atmosphere*: Deep festive ambiance with golden ambient glow.
  2. *Cloud Drift*: Smooth layered SVG clouds entering from left and right with depth.
  3. *Festive Parting*: Clouds separate to reveal glowing diyas, confetti sparkles, and the greeting.
  4. *Personalized Reveal*: Large greeting with the sender's personalized name and character mascot.
  5. *Interactivity*: Direct WhatsApp share, Create Your Own, and Replay animation controls.
- **Official Brand Mascot — Aniket**:
  - High-fidelity anime-style creator with messy black hair, subtle orange highlights, and the official orange ASAI LABS shirt with white "A" logo.
  - Featured in the greeting reveals and the dedicated website development CTA section.
- **1-Click WhatsApp Sharing System**:
  - Encoded click-to-chat links for Dhanteras & Diwali.
  - Web Share API integration with automatic fallback.
  - Instant clipboard copy with feedback.
- **100% Offline Audio Synthesizer**:
  - Built-in Web Audio API Tanpura drone + Raag Yaman/Bhupali festive chime plucks.
  - Zero external network audio files, zero copyright issues, instant playback with clear toggle.
- **Mobile-First & High Performance**:
  - Responsive across all iPhone and Android devices.
  - Respects `prefers-reduced-motion` and throttles particle effects when tabs are hidden.

## 🚀 Running the Project

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build optimized production bundle
npm run build

# 4. Preview production build
npm run preview
```

Server is available locally at `http://localhost:3000/`
